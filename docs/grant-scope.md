# Filecoin Open Grant #2182 scope

## Milestone 1 — $8,000

- Evidence-bundle specification and schemas
- Architecture and privacy model
- Filecoin and Base integration boundaries
- Implementation and test plan

## Milestone 2 — $15,000

- Synapse/Filecoin Onchain Cloud storage adapter
- Local/test and Calibration support
- Retrieval verification
- Verifier CLI and reusable library

## Milestone 3 — $15,000

- SDK and hOUR Chain hooks
- Base settlement integration
- Reference creator-rights workflow
- Automated tests and deployment tooling

## Milestone 4 — $12,000

- One real creator-release pilot
- Public documentation and maintenance guidance
- Deployment evidence and final report

## Open-source commitment

No closed-source component will be used to satisfy a grant milestone. All grant-funded specifications, adapters, SDK code, reference applications, tests, deployment tooling, and documentation will be committed to this repository under `MIT OR Apache-2.0`.
