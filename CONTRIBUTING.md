# Contributing

Contributions are welcome through GitHub issues and pull requests.

Before submitting code:

1. Keep creator data, credentials, private keys, copyrighted media, and confidential agreements out of the repository.
2. Add or update tests for behavior changes.
3. Run `npm test`.
4. Clearly identify which grant milestone or product requirement the change supports.

By contributing, you agree that your contribution is licensed under `MIT OR Apache-2.0`.
